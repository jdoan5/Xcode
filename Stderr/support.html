Frequently asked

What is this for?

You have just seen something you did not expect — a compiler message, an exception, a number that is wrong — and you want to know what caused it. Stderr is a catalogue of exactly those: short Java and Python programs, the output they really produced, and the belief that makes people write them that way.

How do I find the thing I am looking at?

Paste it. The search field takes an error exactly as your terminal printed it, and search runs over the captured output itself rather than over titles. You can also filter by what happened: it refused to run, or it ran and printed the wrong thing.

Is this a course?

No. There are no lessons, no chapters, no progress and no score. Nothing is unlocked and nothing is tracked. You look something up and you leave.

Are the outputs real?

Yes, and this is the part worth knowing. Every program in the app was compiled and run on real Java and Python installations before the app shipped, and the printed lines come from those runs rather than from memory. The authoring format has no field for a hand-written output, so a plausible-looking wrong one cannot be introduced by mistake.

Does the app run code on my device?

No. The outputs are stored text, captured when the catalogue was built. Nothing is compiled, downloaded or executed on your device.

Why are some entries marked "silently wrong"?

Because those are the expensive ones. A program that refuses to compile tells you something is wrong. A program that runs, exits zero and prints the wrong number does not, and that is the bug that reaches production.

Which languages does it cover?

Java and Python today, on iPhone, iPad and Mac. The catalogue is built to take more.

Does it work offline?

Always. There is no networking code in the app at all, so Airplane Mode changes nothing.

Does the app collect any data?

No. No account, no analytics, no tracking, no ads and no servers of our own. See the Privacy Policy.
